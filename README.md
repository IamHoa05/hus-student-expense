Ứng dụng quản lý chi tiêu cho sinh viên

## Frontend environment

The frontend reads `NEXT_PUBLIC_API_URL` to determine the backend base URL. Create a `.env.local` (gitignored) in the repository root with:

```
NEXT_PUBLIC_API_URL=http://localhost:8000
```

You can also copy `.env.example` and adjust values for your environment.
